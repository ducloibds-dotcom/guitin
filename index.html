Khối Liên hệ

            
Không hiện số điện thoại trên trang — chỉ hiện "Gọi ngay để biết thêm thông tin:" + nút Gọi ngay / Zalo ngay / TikTok ngay (nếu có). Số điện thoại chỉ dùng ngầm để tạo link gọi & Zalo.

          

        

        

          
          

            

              
              
            

            

              
              
            

            

              
              
            

            

              
              
            

            

              
              
            

          

          
        

        

          
          
        

        

          ⚡ Số điện thoại chỉ dùng để tạo link "Gọi ngay" / "Zalo ngay", không hiển thị dạng chữ trên trang. Bỏ trống ô TikTok nếu chưa có kênh — nút "TikTok ngay" sẽ tự ẩn khỏi tất cả các dòng.
        

      


      
      

        

          
🗺️

          

            
Bản đồ

            
Nhúng Google Maps. ⚠ Phải làm trên máy tính.

          

        


        

          
📋 Hướng dẫn lấy link nhúng (trên máy tính)

          
1. Mở maps.google.com trên trình duyệt máy tính

          
2. Tìm địa điểm → nhấn nút Chia sẻ

          
3. Chọn tab Nhúng bản đồ

          
4. Nhấn Sao chép HTML → dán toàn bộ vào ô bên dưới

← Dán thẻ iframe bên trên

Khối Đồng hồ

            
Chèn đồng hồ LED chạy realtime vào tin đăng.

          

        

        

          
Xem trước code

          

            
<div class="kenyo-clock kenyo-led">
    <div class="time" id="kenyoTime">.</div>
</div>

          

        

        

          ⚡ Khối này không cần điền gì thêm — bấm "Tạo code" để lấy đoạn HTML chèn vào CMS.
        

      


      
      

        

          
🖼️

          

            
Khối Ảnh

            
Nhiều ảnh, mỗi ảnh có caption/alt/title riêng. Viết caption ảnh 1 → bấm "✓ Tạm ổn" để đồng bộ caption/alt/title cho tất cả ảnh, vẫn sửa lại được từng ảnh sau đó. Bỏ tick ✔ ở đầu ảnh để tạm loại khỏi code lúc đăng mà không cần xóa.

          

        

        

          
          

          
        

        

          ⚡ Dấu "/" dư ở đầu link ảnh sẽ tự động bị xóa khi tạo code.
        

      


      
      

        

          
📕

          

            
Khối Ảnh sổ

            
Nút "Nhấn xem hình ảnh sổ" + gallery ẩn hiện khi bấm. Viết caption ảnh 1 → bấm "✓ Tạm ổn" để đồng bộ caption/alt cho tất cả ảnh. Bỏ tick ✔ để tạm loại ảnh khỏi code mà không cần xóa.

          

        

        

          
          

            
            
          

        

        

          
          
          
          
        

        

          
          

          
        

        

          ⚡ Dấu "/" dư ở đầu link ảnh sẽ tự động bị xóa khi tạo code.
        

      


      
      

        

          
⚖️

          

            
Khối Pháp lý

            
Nút "Nhấn xem hồ sơ pháp lý" + gallery nhúng iframe (Google Drive/Docs...) ẩn hiện khi bấm. Bỏ tick ✔ để tạm loại mục khỏi code mà không cần xóa.

          

        

        

          
          

            
            
          

        

        

          
          
          
          
        

        

          
          

          
        

        

          ⚡ Dùng link nhúng (embed) từ Google Drive/Docs — không phải link tải xuống trực tiếp.
